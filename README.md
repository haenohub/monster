# 몬스터 외형 도감

메이플노트 클래식에서 수집한 몬스터 567종의 이미지 기반 외형 도감입니다.

- 크기 오름차순 기본 정렬, 기본 카드 기준 8열. 이미지 크기에 따라 1배·1.25배·1.5배·2배 카드 사용
- 이미지, 레벨, HP, MP, 물리방어력, 마법방어력 표시
- 81개 외형 타이틀로 필터링, 이름 및 ID 검색
- 567종의 이미지 내장 (악마 슬라임 포함)
- 여러 외형 특징은 복수 타이틀로 분류
- HTML 다운로드 버튼으로 파일 하나를 저장해 오프라인 열람 가능

`index.html`을 브라우저에서 직접 열 수 있습니다. 빌드나 외부 라이브러리가 필요하지 않습니다.

GitHub Pages의 배포 소스는 `main` 브랜치의 루트(`/`)입니다.

몬스터가 한 종뿐이던 타이틀 12개는 유사한 외형을 묶는 타이틀로 통합했습니다. 현재 모든 타이틀은 최소 두 종 이상을 포함하며, 모든 몬스터에 하나 이상의 타이틀을 부여했습니다.

쥐·두더지 분류를 쥐와 포유류로 나누었습니다. 포유류는 기존 동물 타이틀로 분류되지 않는 모래 두더쥐·미요캐츠·별다람쥐를 포함합니다. 해양생물은 핀붐과 물고기·문어·물범·갑각류 외형의 바다 생물을 함께 묶습니다(장난감 외형 제외).

호브·핀호브·헹키·렉스는 호브 타이틀로 통합했습니다. 해골 해적 타이틀은 해적으로 통합했고, 레프러콘 두 종류는 모두 유령으로 분류했습니다.

크기 순 정렬(기본), 레벨 순 정렬, 추천 정렬 버튼을 지원합니다. 크기는 원본 이미지의 너비×높이 면적으로 계산하며 작은 순으로 정렬합니다. 면적이 같으면 레벨 오름차순, 레벨도 같으면 ID 순으로 정렬합니다. 타이틀 필터와 검색 중에도 선택한 정렬 방식이 유지됩니다.

## 몬스터 상세 페이지

카드 전체를 누르면 `monsters/<ID>/`의 자체 상세 페이지로 이동합니다. 모든 567종에 페이지가 있으며 이름·설명·스탯·메이플노트 목록 분류·출현 맵·드롭 아이템과 확률을 표시합니다. 타이틀 필터 버튼은 카드 이동 대신 기존 필터로 작동합니다. 상세 페이지에서 목록으로 돌아오면 필터·검색·정렬·스크롤 위치를 복원합니다.

메이플노트 상세 페이지 576개를 다시 조회해 574개에서 정보를 확인했습니다. 빈 설명·맵·드롭은 미등록 상태로 구분합니다. 내용이 등록되지 않은 것과 드롭 확률 0은 다릅니다.

- `data/monsters.json`: 메이플노트 정보와 사용자가 지정한 타이틀의 스냅샷
- `assets/monsters/`: 목록과 동일한 원본 몬스터 이미지
- `assets/detail.css`, `assets/detail.js`: 상세 페이지 디자인과 드롭 검색
- `scripts/build-monster-pages.py`: 정적 상세 페이지 생성기 (`python scripts/build-monster-pages.py`)

GitHub Pages에서 추가 서버나 빌드 없이 열립니다. 상세 페이지까지 오프라인으로 보려면 저장소 전체를 내려받아 주세요. 목록 HTML만 저장한 경우, 카드 클릭 시 공개 사이트의 상세 페이지로 연결됩니다.

강아지 타이틀을 개로 변경하고 헥터·화이트팽·웨어울프·라이칸스로프를 늑대로 분리했습니다. 가면 사제는 가면과 사제로 나누고, 발굽 동물·박쥐 타이틀은 삭제했습니다. 사용자가 지정한 오물·비행 등의 분류를 추가했습니다.

#9300140 화난 프랑켄로이드, #9300139 프랑켄로이드 및 체리맛·망고맛·멜론맛 버블티를 삭제해 571종으로 정리했습니다. #9300139의 설명은 남은 #9300151 프랑켄로이드와 #9300152 화난 프랑켄로이드에 복사하고 설명 출처를 표시했습니다.

날개 타이틀을 비행으로 변경하고 비행·천사·가면·갑옷 등의 사용자 분류를 반영했습니다. #9400294 듀나스만 삭제하고 #9400270 듀나스 및 #9400293 듀나스 유닛은 유지해 570종으로 정리했습니다. #9400577 파이어브랜드에만 가면을 추가했습니다.

## 추천 정렬

기본 정렬은 크기 순입니다. 추천 정렬에서는 외형이 비슷한 몬스터를 모아 작은 개체 → 성체·강화형 → 직급이 높은 개체·보스로 이어지게 배치합니다. 전체 567종을 이미지로 검토해 522종을 131개 외형 묶음으로 정리했고, 나머지 45종은 단독으로 배치합니다. 묶음은 외형 타이틀과 별개입니다.

성장·강화·직급·변신 단계가 명확한 73개 묶음에는 별도의 진행 순서를 지정했습니다. 이미지에 포함된 꽃·무기·이펙트로 면적이 조금 다르거나 출현 지역이 달라도 이 순서를 우선합니다. 필터·검색으로 일부 몬스터만 남아도 지정한 순서 중 해당하는 몬스터만 표시합니다.

- 뱀: 주니어 네키 → 홍화사 → 청화사 → 벨라모아 → 구렁이 Lv.18 → 구렁이 Lv.60
- 일본 인물: 수하A~D → 간부A·B → 보디가드A·B → 두목 → 여두목 → 영주 → 대보스
- 크림슨우드 인물 보스: 흐살프 → 나그롬 → 렐릭 → 마르가나
- 크림슨우드 가면 전사: 윈드레이더 → 파이어브랜드(변신형 포함) → 나이트섀도우
- 네오도쿄 인물·천사: 이루워터 → 듀나스 → 오베론 → 아우프헤벤. 듀나스 유닛은 비행 병기 묶음에 배치
- 드래곤 보스: 마뇽 → 레비아탄

버섯·돼지·늑대·예티와 눈사람·여우·테니와 유령 테니·장난감 곰 등의 소형·성체·보스도 같은 외형 흐름으로 정리했습니다. 미스릴 뮤테·프릴드·뼈 드래곤·와이번처럼 강화형이 작은 면적 때문에 먼저 나오던 순서를 바로잡고, 파풀라투스·혼테일·베르가모트 등의 전투 단계도 순서대로 배치합니다. 타나토스·에레고스 앞에는 외형이 비슷한 리치를 추가했습니다.

진행 순서를 따로 지정하지 않은 묶음은 같은 출현 지역을 우선해 모으고, 지역 안에서는 원본 이미지 면적 → 레벨 → ID 순으로 정렬합니다. 지역은 메이플노트의 원본 분류를 사용하며 `BOSS`는 지역명에서 제외합니다. 지역이 여러 곳이면 현재 보이는 같은 외형 몬스터들이 가장 많이 공유하는 지역을 선택하고, 동률은 지역명 순으로 결정합니다. 지역 정보가 없는 몬스터는 해당 외형 묶음의 끝에 표시합니다.

외형 묶음 간 순서는 각 묶음에서 레벨 → 면적 → ID 순으로 가장 앞서는 몬스터를 대표값으로 삼아 결정합니다. 묶음 안의 지역별 작은 묶음도 같은 대표값 기준으로 정렬합니다. 필터·검색·정렬 선택은 상세 페이지에서 목록으로 돌아올 때 복원합니다. 기존에 요청한 아이언 뮤테·루모·단지·길거리 물건·티키와 틱톡·테니·세이버의 나란한 배치도 유지합니다.

- `data/sort-families.json`: 외형 묶음. `order: "progression"`이면 `monsterIds`의 순서가 진행 순서이며, 생략하면 지역·크기 정렬 사용
- `python scripts/sync-sort-families.py`: 목록·상세 데이터에 묶음과 `sortFamilyRank`를 동기화하고 중복·잘못된 ID를 검사
- `node scripts/test-recommended-sort.cjs`: 요청한 진행 순서, 81개 타이틀, 검색·필터 후 순서 유지, 지역 우선 보조 정렬, 기본 정렬 검증 (추가 패키지 불필요)
- `python scripts/build-monster-pages.py`: 타이틀과 상세 정보가 바뀐 경우 상세 페이지 갱신

호문의 사물·호문쿨루의 언데드·제노의 로봇 타이틀을 삭제하고 롬바드에 장난감을 추가했습니다. 오버로드 #9400276과 매버릭 Typeβ #9400274·#9400278을 삭제해 현재 567종입니다. 오버로드 #9400254는 유지했습니다.
