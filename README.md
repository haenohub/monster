# 몬스터 외형 도감

메이플노트 클래식에서 수집한 몬스터 570종의 이미지 기반 외형 도감입니다.

- 레벨 오름차순, 기본 카드 기준 8열. 이미지 크기에 따라 1배·1.25배·1.5배·2배 카드 사용
- 이미지, 레벨, HP, MP, 물리방어력, 마법방어력 표시
- 81개 외형 타이틀로 필터링, 이름 및 ID 검색
- 570종의 이미지 내장 (악마 슬라임 포함)
- 여러 외형 특징은 복수 타이틀로 분류
- HTML 다운로드 버튼으로 파일 하나를 저장해 오프라인 열람 가능

`index.html`을 브라우저에서 직접 열 수 있습니다. 빌드나 외부 라이브러리가 필요하지 않습니다.

GitHub Pages의 배포 소스는 `main` 브랜치의 루트(`/`)입니다.

원본 사이트의 데이터 및 이미지에 대한 권리는 각 권리자에게 있습니다. 타이틀은 외형을 보고 분류한 비공식 분류이며, 원본에 없는 값은 `—`로 표시했습니다.

이미지는 원본 픽셀 크기를 기준으로, 기본·1.25배·1.5배·2배 카드 중 들어가는 가장 작은 카드에 표시합니다. 2배 카드에도 들어가지 않는 이미지만 비율을 유지해 축소합니다. 창 크기나 필터가 바뀌어도 카드 크기를 자동으로 다시 계산합니다. 악마 슬라임은 첨부 이미지와 같은 스프라이트의 대만 버전 원본을 사용했습니다: https://maplestory.io/api/TMS/209/mob/9410039/icon

몬스터가 한 종뿐이던 타이틀 12개는 유사한 외형을 묶는 타이틀로 통합했습니다. 현재 모든 타이틀은 최소 두 종 이상을 포함하며, 모든 몬스터에 하나 이상의 타이틀을 부여했습니다.

쥐·두더지 분류를 쥐와 포유류로 나누었습니다. 포유류는 기존 동물 타이틀로 분류되지 않는 모래 두더쥐·미요캐츠·별다람쥐를 포함합니다. 해양생물은 핀붐과 물고기·문어·물범·갑각류 외형의 바다 생물을 함께 묶습니다(장난감 외형 제외).

호브·핀호브·헹키·렉스는 호브 타이틀로 통합했습니다. 해골 해적 타이틀은 해적으로 통합했고, 레프러콘 두 종류는 모두 유령으로 분류했습니다.

레벨 순 정렬(기본)과 크기 순 정렬 버튼을 지원합니다. 크기는 원본 이미지의 너비×높이 면적으로 계산하며 작은 순으로 정렬합니다. 면적이 같으면 레벨 오름차순, 레벨도 같으면 ID 순으로 정렬합니다. 타이틀 필터와 검색 중에도 선택한 정렬 방식이 유지됩니다.

## 몬스터 상세 페이지

카드 전체를 누르면 `monsters/<ID>/`의 자체 상세 페이지로 이동합니다. 모든 570종에 페이지가 있으며 이름·설명·스탯·메이플노트 목록 분류·출현 맵·드롭 아이템과 확률을 표시합니다. 타이틀 필터 버튼은 카드 이동 대신 기존 필터로 작동합니다. 상세 페이지에서 목록으로 돌아오면 필터·검색·정렬·스크롤 위치를 복원합니다.

메이플노트 상세 페이지 576개를 다시 조회해 574개에서 정보를 확인했습니다. 매버릭 Typeβ(ID 9400274, 9400278)는 원본 상세 페이지가 없어 지역별 목록 정보만 표시합니다. 빈 설명·맵·드롭은 미등록 상태로 구분합니다. 내용이 등록되지 않은 것과 드롭 확률 0은 다릅니다.

- `data/monsters.json`: 메이플노트 정보와 사용자가 지정한 타이틀의 스냅샷
- `assets/monsters/`: 목록과 동일한 원본 몬스터 이미지
- `assets/detail.css`, `assets/detail.js`: 상세 페이지 디자인과 드롭 검색
- `scripts/build-monster-pages.py`: 정적 상세 페이지 생성기 (`python scripts/build-monster-pages.py`)

GitHub Pages에서 추가 서버나 빌드 없이 열립니다. 상세 페이지까지 오프라인으로 보려면 저장소 전체를 내려받아 주세요. 목록 HTML만 저장한 경우, 카드 클릭 시 공개 사이트의 상세 페이지로 연결됩니다.

강아지 타이틀을 개로 변경하고 헥터·화이트팽·웨어울프·라이칸스로프를 늑대로 분리했습니다. 가면 사제는 가면과 사제로 나누고, 발굽 동물·박쥐 타이틀은 삭제했습니다. 사용자가 지정한 오물·비행 등의 분류를 추가했습니다.

#9300140 화난 프랑켄로이드, #9300139 프랑켄로이드 및 체리맛·망고맛·멜론맛 버블티를 삭제해 571종으로 정리했습니다. #9300139의 설명은 남은 #9300151 프랑켄로이드와 #9300152 화난 프랑켄로이드에 복사하고 설명 출처를 표시했습니다.

날개 타이틀을 비행으로 변경하고 비행·천사·가면·갑옷 등의 사용자 분류를 반영했습니다. #9400294 듀나스만 삭제하고 #9400270 듀나스 및 #9400293 듀나스 유닛은 유지해 현재 570종입니다. #9400577 파이어브랜드에만 가면을 추가했습니다.

## 추천 정렬

기본 정렬은 기존 레벨 순입니다. 추천 정렬을 선택하면 관계가 명확한 색상 변형·강화형·진화형 등을 묶어서 표시합니다. 464종을 159개 묶음으로 정리했으며, 관계가 불분명한 106종은 각각 단독으로 배치합니다. 묶음은 타이틀과 별개이며 필터를 추가하지 않습니다.

필터와 검색을 통과한 몬스터만 대상으로 묶습니다. 묶음 안에서는 레벨 → 원본 이미지 면적 → ID 순으로 정렬하고, 첫 번째 몬스터를 대표값으로 삼아 묶음들을 같은 기준으로 정렬합니다. 따라서 비슷한 몬스터가 다른 몬스터 사이로 흩어지지 않습니다. 묶음에 속하지 않은 몬스터도 같은 레벨·크기 기준을 따릅니다.

- `data/sort-families.json`: 관련 몬스터 묶음과 ID 목록
- `python scripts/sync-sort-families.py`: 목록과 상세 데이터에 묶음 정보를 동기화
- `python scripts/build-monster-pages.py`: 타이틀과 상세 페이지 갱신

아이언 뮤테, 루모, 단지, 길거리 물건, 티키·틱톡, 테니, 세이버 등의 요청한 묶음에 더해 다른 명확한 변형 계열도 함께 정리했습니다. 추천 정렬 상태 역시 상세 페이지에서 목록으로 돌아올 때 복원됩니다.
